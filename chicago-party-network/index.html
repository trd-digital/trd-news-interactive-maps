    Sources and how to check
    • Deeds, mortgages, assignments and foreclosure filings (lis pendens): Cook County Clerk recordings, crs.cookcountyclerkil.gov. Every such link has a Clerk search link and, where we have it, the Clerk document page. A PIN opens every recording on that parcel.
    • Reporters’ tags (T-, R-, UR-), attorneys / agents and PTAX-203 preparers, and the building list: the reporters’ own spreadsheet pin histories of source examples.xlsx, sheet “examples pinhist transactions”.
    • Officer / manager / agent “of the company” links: OpenCorporates / Illinois Secretary of State company records (files owner_entity_map.csv and combined_entity_officer.csv). Each one links to its OpenCorporates page.
    • Which party a building is tied to: the Q1 pipeline’s ownership-based list, foreclosure_questions/variant_pinhist/building_units_sqft.csv, column tagged_parties (the same list as the workbook’s violations tab): 243 buildings.
    • The data behind this page: variant_pinhist/network/network_nodes.csv, network_edges.csv and README.txt (column definitions), built by nb/pipeline_pinhist.ipynb.
    • In Excel: the same rows are in variant_pinhist/q1_part2_workbook_pinhist.xlsx, tabs R_network_nodes and R_network_edges. The “edge N” number shown on each link here is the edge_id column there.
    • Clerk links: the Clerk’s site keeps one search per browser session, so a second link opened in the same session can show the first search again. Open each link in a new private window if the result looks wrong.
